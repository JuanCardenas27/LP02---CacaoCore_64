### Convención de uso de registros
R0 = n (Numero de elementos)
R1 = i (Indice para recorrer el arreglo)
R2 = max (Valor Maximo encontrado)
R4 = i*8 (index * 8)
R5 = dir array[i] (direccion a comparar)
R6 =  value array[i] (valor a comparar)
R11 = Dirección de inicio de impresión
R12 = Longitud (bytes) de impresión
